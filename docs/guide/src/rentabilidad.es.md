La pestaña **Resumen** del expediente calcula todo desde los documentos (pedidos, facturas, facturas de proveedor,
abonos), en la moneda de la compañía y sin impuestos salvo donde se indica. No se escribe ningún importe a mano.

| Cifra | Qué es |
|---|---|
| Venta acordada | Total de las ventas confirmadas del expediente (incluidas las añadidas después). |
| de ello, servicios BOSS / suplidos | Parte hecha por BOSS y parte pagada en nombre del cliente. |
| Facturado / Por facturar | Facturas de cliente contabilizadas menos abonos; lo que falta. |
| Cobrado (con impuestos) | Lo cobrado de esas facturas. |
| Coste previsto en la aceptación | Coste de los servicios de proveedor guardado al aceptar. |
| Compras comprometidas | Pedidos de compra confirmados. |
| Coste real | Facturas de proveedor contabilizadas menos abonos de proveedor (cuenta analítica del expediente). |
| Coste aún previsto | Lo pedido o previsto que aún no tiene factura de proveedor. |
| Coste final previsto | Coste real + coste aún previsto. Nunca suma dos veces un pedido y su factura. |
| Margen en la aceptación | Venta aceptada menos coste aceptado. |
| Margen tras costes externos | Venta acordada menos coste final previsto. |
| Costes completos | Todo coste facturado o cerrado: solo entonces el margen es definitivo. |

**Servicios propios**: el margen es **tras costes externos**; el trabajo del personal de BOSS no es un coste aquí, así
que no es el beneficio neto.

**Diferencias**: en cada servicio a comprar, **Diferencia** = facturado − pedido (o previsto). Una diferencia se revisa
marcando **Diferencia revisada** con una nota; el precio de venta nunca cambia solo.
