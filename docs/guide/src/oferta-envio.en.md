In the **[[Envío]]** (Shipment) tab you enter, once, the data prices need. Lines read them from here: nothing is
typed twice.

![Shipment tab of the quotation](img/02-oferta-envio.png)

| Field | Used for |
|---|---|
| Direction, Transport mode, Load type | Choose the applicable tariffs (import/export, sea/air/road, FCL/LCL/air) |
| Spanish port / airport | Port-specific tariffs (e.g. port occupancy in Valencia or Barcelona) and VAT zone (Canaries) |
| Country abroad | Origin of an import or destination of an export: country tariffs (FuelEU) and VAT |
| Inland province | Pickup/delivery place in Spain: hauliers' zones |
| Carrier | Selects the tariffs of that shipping line, airline or haulier |
| Planned date | ETA for imports, ETD for exports: **chooses the version** of each tariff |
| Containers | Size (20'/40'/45'), type (DV, HC, RF, OT, FR, TK) and quantity |
| Gross weight, volume, pallets, AWB chargeable weight | Services per kg, tonne, m³, W/M, pallet or air waybill kg |
| Goods value, customs duties (estimate) | Percentages (insurance, customs guarantee) |
| Days in storage (estimate) | Time-based services (demurrage, port occupancy, storage): 0 by default |

> When a tariff needs data that is empty, the line says so ("Fill in on the quotation: Carrier") instead of
> inventing a value.
