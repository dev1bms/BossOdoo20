The **Summary** tab of the file computes everything from the documents (orders, invoices, vendor bills, credit notes),
in company currency and untaxed except where stated. No amount is typed.

| Figure | What it is |
|---|---|
| Agreed sale | Total of the confirmed sales of the file (services sold later included). |
| of which BOSS services / paid on behalf | Part done by BOSS and part paid in the customer's name. |
| Invoiced / To invoice | Posted customer invoices minus credit notes; what is left. |
| Collected (with taxes) | What was collected of those invoices. |
| Expected cost at acceptance | Cost of the supplier services kept on acceptance. |
| Committed purchases | Confirmed purchase orders. |
| Actual cost | Posted vendor bills minus vendor credit notes (file's analytic account). |
| Cost still expected | What is ordered or expected and not billed yet. |
| Forecast final cost | Actual cost + cost still expected. A purchase order and its bill are never counted twice. |
| Margin at acceptance | Accepted sale minus accepted cost. |
| Margin after external costs | Agreed sale minus forecast final cost. |
| Costs complete | Every cost billed or closed: only then is the margin final. |

**Own services**: the margin is **after external costs**; BOSS staff work is not a cost here, so it is not the net
profit.

**Variances**: on each service to buy, **Variance** = billed − ordered (or expected). A variance is reviewed by ticking
**Variance reviewed** with a note; the sale price never changes by itself.
